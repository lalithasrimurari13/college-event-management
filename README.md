# College Event Management System

A simple web app to manage and track college events. Built with plain HTML, CSS, and JavaScript — no backend, no frameworks. Events are saved in the browser using localStorage.

## What it does

- Add events with a name, date/time, club, and venue
- Shows a live countdown to each upcoming event
- Search events by name or venue
- Filter by club and by status (upcoming/completed)
- Sort events by nearest or latest date
- Mark events as completed or reopen them
- Delete events
- Dashboard showing total events, upcoming, completed, and number of clubs
- Data stays saved in the browser after refresh (localStorage)

## Tech used

- HTML
- CSS
- JavaScript

## How to run

Just open `index.html` in your browser. No installation needed.

## Note

This project stores data only in your browser (localStorage). It's not shared across devices, and clearing browser data will remove your events.
